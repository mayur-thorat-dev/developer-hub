# Demo 02 - HTML Hyperlinks and A to Z Navigation

## About

In this demo, I created one main HTML page with A to Z alphabet links. I used the anchor tag to connect different HTML pages. When I click on any alphabet, its page opens.

## HTML Tags Used

- `<html>` - Main HTML tag.
- `<head>` - Contains page information.
- `<meta>` - Used for character encoding and viewport.
- `<title>` - Sets the page title.
- `<body>` - Contains the content of the page.
- `<h2>` - Used to display a heading.
- `<a>` - Used to create links.

## What I Created

- One main HTML page.
- A to Z alphabet links.
- Separate pages for each alphabet.
- Links to navigate between pages.
- A link to go back to the main page.

## What I Learned

- How to use the anchor tag.
- How to create links using HTML.
- How to use the `href` attribute.
- How to connect two HTML pages.
- How to move from one page to another.
